# 006 — 图片路径含空格时被当作纯文本，源码印进成品文档

| 项目 | 值 |
|---|---|
| 状态 | fixed |
| 严重度 | 中（Windows 上文件名含空格极常见；触发即产出带源码的文档） |
| 发现日期 | 2026-09-17 |
| 记录时 commit | `baa43c8`（修复前） |
| 修复位置 | 新增 `scripts/md-repair.js` 的 `repairUnescapedImagePaths()`；`scripts/preprocess.js` 与 `scripts/md2docx.js` 均接入（双路一致） |
| 回归用例 | `md/qa/spaceimg/` + `scripts/verify-sections-and-images.sh` 步骤 3 |

## 1. 现象

Markdown 里图片路径含空格且未转义时（如 `![图B](assets/我的 图片.png)`），
该引用**不被解析为图片**，而是作为纯文本原样输出。成品 DOCX 中出现一行
Markdown 源码：

```text
![图B](assets/我的 图片.png)
```

既不是图片，也没有任何报错——比"图片缺失占位"更糟（占位至少提示有问题，
这里看起来像是作者自己写错了正文）。

## 2. 最小复现

```markdown
![图A](assets/diagram.png)                      ← 对照：正常
![图B](assets/我的 图片.png)                     ← 裸空格（本缺陷）
![图C](<assets/我的 图片.png>)                   ← 尖括号（合法）
![图D](assets/%E6%88%91%E7%9A%84%20...png)       ← %20 转义（合法）
```

**实测观测**（修复前）：

| 运行方式 | 嵌入图片 | 产物中的残留源码 |
|---|---|---|
| 完整流水线 `md2docx.sh` | 3 | 有（`![图B](...)`） |
| 直接 `md2docx.js` | 3 | 有（同上） |

## 3. 根因

**这是 CommonMark 的规范行为，不是 markdown-it 的缺陷**：链接/图片目标中出现
裸空格时，必须用 `<>` 包裹或 `%20` 转义，否则该构造不被识别为链接/图片。

实测 markdown-it 对三种写法：

| 写法 | 是否产出 image token |
|---|---|
| `![](assets/a b.png)` | **否** |
| `![](<assets/a b.png>)` | 是（src 为 `assets/a%20b.png`） |
| `![](assets/a%20b.png)` | 是 |

因此工具侧要做的是**兼容修复**而非修 bug：把作者写的裸空格形式补成合法形式。

## 4. 影响

- **Windows 用户必踩**：资源管理器允许文件名含空格，`我的 图片.png`、
  `架构 图.png` 是极自然的命名；这类引用一旦出现就会在文档里留下源码行。
- 属"静默失败"模式（不报错、只是产出错内容），与 `AGENTS.md` 已知陷阱
  第 12、14 条同类。
- 与规范关系：`01-base/技术文档格式-20260525.md` 未规定图片来源，
  但成品出现 Markdown 源码显然属输出完整性问题。

## 5. 修复

新增共享模块 `scripts/md-repair.js`，导出 `repairUnescapedImagePaths()`：
把 `![alt](路径 含 空格)` 改写为 `![alt](<路径 含 空格>)`。

**为什么单独成模块**：本缺陷最初只在 `preprocess.js` 里修，验证时发现
直接跑 `md2docx.js` 仍有问题（3 张图 + 残留源码）——即**双路不一致**。
按项目既有模式（如 `exec-util.js`）抽成共享模块，两条路径共用同一实现。

安全约束（避免误伤正文与既有合法写法）：

- 围栏代码块内（``` / ~~~）不改写
- 已是 `<...>` 尖括号写法的不动
- 已用 `%20` 转义的不动
- 正则排除 `()<>`，故括号内含嵌套括号的不匹配
- **改写后用 markdown-it 复验能解析出 image token，否则回滚原文**
  （宁可原样保留，也不做无法确认安全的改写）

## 6. 验证

| 用例 | 期望 | 实测 |
|---|---|---|
| `![图B](assets/我的 图片.png)` | 改写为 `<...>` | ✅ |

| `![图D](assets/%20...)` | 不动 | ✅ |
| `![图A](assets/diagram.png)` | 不动 | ✅ |
| 正文中行内出现 `![x](a b.png)` | 改写 | ✅ |
| 一行内混合（仅后者含空格） | 只改后者 | ✅ |
| 围栏代码块内 | 不改写 | ✅ |

| 运行方式 | 修复前 | 修复后 |
|---|---|---|
| 完整流水线 | 3 张图 + 残留源码 | **4 张图，无残留** ✅ |
| 直接 `md2docx.js` | 3 张图 + 残留源码 | **4 张图，无残留** ✅ |
