# docs/archived — 归档文档

本目录存放已**过时/失效**的设计方案与评审文档。归档规则（见 `AGENTS.md`）：

- **plans/** — 已被更新版本替代（如 v1/v3/v4 → v5）、已实施完成、或已标记 `deprecated` 放弃的方案
- **review/** — 针对已归档/已实施方案的评审记录（评审使命已完成）

## 归档原则

1. **只归档，不删除** — 保留决策痕迹，供日后回溯"为什么这么做/为什么不做某方案"。
2. **当前有效文档保留在原处** — 如 `docs/plans/large-image-landscape-v5.md`（当前横置架构的设计依据），留在活跃目录。
3. **新方案/新评审**继续写入 `docs/plans/`、`docs/review/`，与归档区隔离。
